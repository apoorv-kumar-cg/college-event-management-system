# College-Event-Management-System

A web-based **College Event Management System** designed to simplify the planning, organization, and management of college events. The system brings different event-related responsibilities together in one platform, making event coordination more organized and efficient.

## About the Project

Managing college events involves multiple teams such as treasurers, designers, caterers, cultural teams, and guest coordinators. Our system provides dedicated sections for each role, allowing them to manage their respective tasks efficiently.

The goal of this project is to create a centralized platform where event organizers can coordinate activities, manage resources, and keep track of important event information.

## Features

## Event management and organization
*  **Treasurer** – Manage budgets, income, expenses, and payments
*  **Designer** – Manage posters, banners, invitations, and promotional content
*  **Caterer** – Manage menus, food requirements, and catering arrangements
*  **Cultural Program** – Manage performances, programs, and participant registrations
*  **Invite Guest** – Manage guest invitations, details, and invitation status
*  Organized dashboards and event information
*  Easy coordination between different event teams

## Team Roles

| Role              | Responsibility                            |
